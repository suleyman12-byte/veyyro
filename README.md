# Telegram-бот для оценки внешности

Бот анализирует фото лица и выставляет оценку от 1 до 10 по 6 критериям:
- Симметрия лица
- Пропорции (третьи лица)
- Золотое сечение
- Глаза
- Губы
- Кожа

Использует **MediaPipe Face Mesh** (468 точек лица) для анализа.

---

## Быстрый старт (локально)

### 1. Создайте бота в Telegram

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте команду `/newbot`
3. Придумайте имя бота (например: `Beauty Score Bot`)
4. Придумайте username (например: `my_beauty_score_bot`) — должен заканчиваться на `bot`
5. BotFather пришлёт вам **токен** — скопируйте его

### 2. Установите зависимости

```bash
# Создайте виртуальное окружение (рекомендуется)
python -m venv venv

# Активируйте его
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### 3. Запустите бота

```bash
# Установите токен бота
# Windows (PowerShell):
$env:BOT_TOKEN="ваш_токен"

# macOS/Linux:
export BOT_TOKEN="ваш_токен"

# Запустите бота
python bot.py
```

Бот запущен! Откройте его в Telegram и отправьте фото.

## Деплой на Render (бесплатно, 24/7)

### 1. Загрузите код на GitHub

```bash
cd beauty-bot
git init
git add .
git commit -m "Initial commit"
```

Создайте репозиторий на [github.com](https://github.com) и загрузите код:

```bash
git remote add origin https://github.com/ваш_логин/beauty-bot.git
git branch -M main
git push -u origin main
```

### 2. Разверните на Render

1. Зарегистрируйтесь на [render.com](https://render.com) (бесплатно)
2. Нажмите **New +** → **Web Service**
3. Подключите ваш GitHub-репозиторий `beauty-bot`
4. Настройки:
   - **Name**: `beauty-bot`
   - **Runtime**: `Docker`
   - **Plan**: `Free`
5. В разделе **Environment Variables** добавьте:
   - Key: `BOT_TOKEN`
   - Value: `ваш_токен_бота`
6. Нажмите **Create Web Service**

Render автоматически соберёт Docker-образ и запустит бота!

### Важно о бесплатном тире Render

- Сервис засыпает после 15 минут бездействия
- При первом сообщении бот может отвечать с задержкой ~30 секунд (пока "просыпается")
- Это нормально и бесплатно!

## Как работает оценка

Бот использует **MediaPipe Face Mesh** для определения 468 точек лица.
Затем вычисляются:

| Критерий | Вес | Описание |
|----------|-----|----------|
| Симметрия | 30% | Горизонтальная и вертикальная симметрия лица |
| Пропорции | 25% | Равномерность трёх частей лица |
| Золотое сечение | 20% | Соответствие пропорций золотому числу (1.618) |
| Глаза | 10% | Размер, форма, открытость |
| Губы | 10% | Полныесть, симметрия |
| Кожа | 5% | Гладкость, тон |

Итоговая оценка: **1-10 баллов** (с небольшой случайной вариацией для разнообразия).

## FAQ

**Q: Бот не отвечает?**
A: Проверьте, что токен введён правильно. Убедитесь, что бот запущен.

**Q: "Лицо не обнаружено"?**
A: Отправьте фото анфас с хорошим освещением. Уберите очки, маски.

**Q: Можно ли изменить критерии?**
A: Да! Измените веса в функции расчёта итоговой оценки в `bot.py`.

**Q: Бот платный?**
A: Нет! Используются только бесплатные библиотеки и бесплатный тир Render.
